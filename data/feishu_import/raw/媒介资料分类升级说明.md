- 自动扫描媒介资料文件夹

- 计算流程完整度

**传播流程阶段识别**：
1. **环境洞察**：环境分析、社交舆论、用户画像、竞品分析
2. **策略制定**：媒介策略、传播规划、战术说明
3. **资源评估**：资源评估、资源盘点、植入评估
4. **执行投放**：投放执行、KOL合作、剧集植入
5. **效果监测**：效果分析、数据报告、收视率监测
6. **经验沉淀**：案例分享、项目结案、复盘总结

**识别标准**：
- 至少包含4个传播阶段
- 计算流程完整度（找到的阶段数/总阶段数）
- 流程连续性加分（连续阶段越多，完整度越高）

## 🎯 新增分类说明

### 分类1：传播全流程案例 ⭐

**定义**：包含完整传播流程的案例，涵盖从环境洞察到策略制定、资源评估、执行投放、效果监测、经验沉淀的全流程。

**识别方式**：
- 使用 `extract_communication_flow_cases.py` 工具自动识别
- 不依赖文件名关键词匹配
- 基于文件内容和路径分析

**典型案例**：
- 东阿阿胶完整传播案例
- 健力宝春战传播案例

### 分类2：媒介资料 ⭐

**定义**：媒介相关的所有资料，包括媒介地图、投放策略、环境分析、资源评估、竞品报告、社交舆论、用户画像、行业案例等。

**子分类**：
1. 媒介地图
2. 媒介投放策略
3. 媒介环境分析
4. 媒介资源评估
5. 社交舆论风向
6. 社媒用户画像&收视率
7. 竞品报告
8. 行业案例分享

**关键词**：38个媒介相关关键词（详见代码）

## 📊 传播流程逻辑

### 完整传播流程

```
环境洞察 → 策略制定 → 资源评估 → 执行投放 → 效果监测 → 经验沉淀
```

### 各阶段说明

1. **环境洞察**
   - 媒介环境分析（区域、行业）
   - 社交舆论风向监测
   - 用户画像分析
   - 竞品分析研究

2. **策略制定**
   - 年度/季度/月度媒介传播规划
   - 媒介投放策略制定
   - 战术说明与执行计划

3. **资源评估**
   - 媒介资源盘点与评估
   - 剧集植入评估
   - IP合作评估
   - 媒介地图建立

4. **执行投放**
   - 投放排期与执行
   - KOL/达人合作
   - 剧集/综艺植入
   - 全媒体整合投放

5. **效果监测**
   - 收视率数据监测
   - 社交声量分析
   - 效果评估与ROI分析
   - 投放总结与回顾

6. **经验沉淀**
   - 案例分享与复盘
   - 项目结案报告
   - 经验总结与优化建议

## 🔧 工具使用方法

### 1. 文件分类

**主分类工具**：
```bash
python classify_reports.py
```

**增量分类工具**：
```bash
python classify_new_reports.py
```

### 2. 传播全流程案例提取

```bash
python extract_communication_flow_cases.py
```

**输出**：
- `传播全流程案例报告.json`：包含所有完整流程案例的详细信息

**报告内容**：
- 品牌/项目名称
- 流程完整度
- 包含的阶段
- 文件列表（按阶段分类）
- 文件数量统计

## 🎓 使用建议

### 1. 新文件分类
- 将新文件放在"公关报告合集"根目录
- 运行 `classify_new_reports.py` 自动分类
- 媒介相关文件会自动归入"媒介资料"

### 2. 传播流程案例提取
- 定期运行 `extract_communication_flow_cases.py`
- 查看生成的案例报告
- 重点关注完整度 >= 60% 的案例

### 3. 案例学习
- 使用完整流程案例作为学习参考
- 分析不同品牌的传播策略
- 总结成功经验与最佳实践
