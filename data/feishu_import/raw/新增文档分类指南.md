# 新增文档分类指南

当您有新的公关报告需要添加到"公关报告合集"时，请按照以下步骤操作：

---

## 📋 快速开始

### 步骤1：将新文件放入根目录

将新文档直接放入 `公关报告合集` 文件夹的**根目录**（不要放入任何分类子文件夹）。

```
公关报告合集/
├── 分类标准说明.md
├── 新增文档分类指南.md
├── 新文件1.pdf          ← 新文件放在这里
├── 新文件2.docx         ← 新文件放在这里
├── 品牌案例/
├── 活动策划/
├── 整合营销/
└── ...
```

### 步骤2：运行分类工具

在项目根目录运行以下命令：

```bash
py classify_new_reports.py
```

或者：

```bash
python classify_new_reports.py
```

### 步骤3：确认分类结果

工具会自动：
1. 扫描根目录下的新文件
2. 根据文件名自动分类
3. 显示分类预览
4. 询问是否确认分类

确认后，文件会自动移动到对应的分类文件夹中。

---

## 🔍 分类原理

工具会根据文件名中的关键词自动判断分类，分类规则如下：

| 类别 | 关键词示例 |
|------|----------|
| **品牌案例** | case_、品牌案例、案例解析、品牌升级 |
| **行业研究** | research_、industry_、麦肯锡、奥美、白皮书 |
| **工具包** | toolkits_、知识地图、话术、直播大纲 |
| **方法论** | 华与华、广告修辞学、方法论 |
| **招商方案** | 招商方案、招商手册、IP合作、通案 |
| **活动策划** | 活动策划、活动方案、双节、中秋、国庆 |
| **品牌手册** | 品牌手册、品牌资料、品牌书 |
| **整合营销** | 整合营销、营销传播、运营方案、抖音运营 |
| **设计规划** | 设计方案、景观设计、规划方案、产品户型 |
| **其他** | 无法匹配的文件 |

详细分类标准请参考：`分类标准说明.md`

---

## ⚠️ 注意事项

### ✅ 正确操作

1. **文件放在根目录**：新文件必须放在 `公关报告合集` 根目录
2. **确认文件名**：确保文件名包含能体现文件类型的关键词
3. **运行分类工具**：使用 `classify_new_reports.py` 进行分类
4. **手动调整**：如果分类不准确，可以手动移动到正确的文件夹

### ❌ 错误操作

1. ❌ 不要直接将文件放入分类子文件夹
2. ❌ 不要重命名已分类的文件（除非需要重新分类）
3. ❌ 不要删除 `分类记录.json` 文件（这是分类记录）

---

## 🔄 重新分类文件

如果需要重新分类某个文件：

### 方法1：使用增量分类工具

1. 将文件从分类文件夹移回根目录
2. 重命名文件，添加更准确的关键词
3. 运行 `classify_new_reports.py`

### 方法2：手动移动

1. 直接将文件移动到正确的分类文件夹
2. 如果文件名重复，系统会自动添加序号

---

## 📝 分类记录

分类工具会自动生成 `分类记录.json` 文件，记录所有文件的分类信息：

```json
{
  "files": {
    "文件名.pdf": {
      "original_name": "文件名.pdf",
      "category": "品牌案例",
      "target_name": "文件名.pdf",
      "classified_at": "2025-01-15T10:30:00"
    }
  },
  "last_update": "2025-01-15T10:30:00"
}
```

这个文件可以帮助您：
- 追踪文件的分类历史
- 了解分类时间
- 恢复误操作的文件

## ❓ 常见问题

### Q1: 文件被错误分类了怎么办？

**A**: 可以手动将文件移动到正确的分类文件夹，或者：
1. 将文件移回根目录
2. 重命名文件，添加更准确的关键词
3. 重新运行分类工具

### Q2: 文件名没有明显关键词怎么办？

**A**: 如果工具无法自动分类，文件会被放入 `其他/` 文件夹。您可以：
1. 手动移动到正确的分类文件夹
2. 重命名文件，添加能体现类型的关键词

### Q3: 如何批量分类多个文件？

**A**: 将所有新文件放入根目录，一次性运行 `classify_new_reports.py`，工具会自动批量处理所有新文件。

### Q4: 分类记录文件被删除了怎么办？

**A**: 删除 `分类记录.json` 不会影响已分类的文件，只是丢失了分类历史记录。可以继续正常使用分类工具。

### Q5: 文件已经在分类文件夹中了，会重复分类吗？

**A**: 不会。工具只会处理根目录下的文件，忽略所有分类文件夹中的文件。

- 哪些文件被分类过
- 分类时间
- 原始文件名和目标文件名
